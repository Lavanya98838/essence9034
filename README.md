# 🍽️ Essence — Restaurant Website

A multi-page restaurant website built with pure **HTML, CSS, and JavaScript**, featuring online menu browsing, table booking, cart functionality, and Firebase-powered backend integration.

---

## 🚀 Features

- **Home Page** — Hero section with restaurant branding and highlights
- **Menu Page** — Browse food items organized by category with images
- **Cart System** — Add items to cart and manage orders via JavaScript
- **Table Booking** — Reservation form with date and time selection
- **Location Page** — Find the restaurant with location details
- **About Page** — Restaurant story and team information
- **Email Integration** — Contact and inquiry handling via mail.js
- **Firebase Integration** — Backend support for booking and order data

---

## 🛠️ Tech Stack

| Technology | Usage |
|-----------|-------|
| HTML5 | Page structure and content |
| CSS3 | Styling, layouts, responsive design |
